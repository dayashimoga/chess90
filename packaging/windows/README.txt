======================================================
  CHESSMASTER - 90-DAY CHESS MASTERY PLATFORM (v1.3.0)
======================================================

QUICK START INSTRUCTIONS:
-------------------------
1. If you downloaded the ZIP archive, EXTRACT ALL files to a folder
   on your computer (e.g. C:\ChessMaster or Desktop\ChessMaster).
   Do NOT run directly from inside the Windows ZIP preview!

2. Launching ChessMaster:
   - Double-click "ChessMaster.exe" (or "ChessMaster-Portable.exe").
   - Alternatively, double-click "Launch-ChessMaster.bat".

3. If you want a standard Windows installation with Desktop & Start
   Menu shortcuts, download and run "ChessMaster-Setup.exe".

REQUIREMENTS:
-------------
- Windows 10 / 11 (64-bit)
- Offline-first architecture: No persistent internet connection required.
