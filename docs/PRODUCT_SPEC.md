# ChessMaster Product Specification

## Product Principles

### 1. The Operational Mastery Loop
Everything in ChessMaster operationalizes the sequence:
`Understand → Recognize → Calculate → Apply → Play → Analyze → Diagnose → Retrain → Retest → Retain`

### 2. The User Loop
`Diagnostic → Skill Graph → Adaptive Daily Plan → Labs → Serious Game → Self-Analysis → Engine Analysis → Root Cause → Retraining → Exam`

### 3. Absolute Authenticity Guarantee
- No reading-only lessons
- No fake progress bars or arbitrary XP
- No dummy features or locked labs
- No placeholders or "coming soon" dead ends
- No hardcoded success or mocks presented as real.

### 4. FIDE Title Integrity
- ChessMaster certifies analytical stamina and mastery of GM-level thought processes, but explicitly disclaims official FIDE GM titles, which require in-person participation in official FIDE norm tournaments.

## User Personas & Modes
1. **Intensive GM Candidate (Full 8-Hour Mode)**:
   - Tactics & vision: 50m
   - Concrete calculation: 90m
   - Positional strategy / curriculum: 60m
   - Endgame mastery: 60m
   - Opening repertoire & model games: 45m
   - Classical tournament game: 120m
   - Self-analysis & root-cause audit: 60m
   - Weakness retraining & spaced review: 30m.
2. **Serious Club Player (60-Minute Standard Mode)**:
   - Spaced review: 10m
   - Core curriculum lab: 25m
   - Serious game & self-analysis: 25m.
3. **Time-Constrained Player (15-Minute Express Mode)**:
   - Spaced review queue clearance: 5m
   - High-intensity weakness drill: 10m.
